# 0064. A tooltip or a user-facing string needs the maintainer's approval

Verbatim guide text at 971fede, copied before the edit to the template.

## From `CLAUDE.md`, line 63

**Two of them are not yours to decide.** Never add a tooltip without asking the maintainer first — recommending one is welcome, adding one unasked is not, and the reason is that a tooltip does not exist on touch, so a phone reader simply loses whatever it carries. And **never add or reword a user-facing string without confirming it first**: every label, message, legend line and button in this app has been read and approved, which is why they are consistent, and a string invented mid-change is the one thing code review reliably misses.
