**Where a rule lives is decided by what it needs to know** (#379): a ban a pattern over class names can settle is a `no-restricted-syntax` rule in `frontend/tools/eslint/eslint.config.js`, where it runs in the editor and reads string literals rather than a file's bytes; a check that measures something — a contrast ratio, a pixel sum, a width read off a role, a count of approved tooltips — stays in `styles.test.ts`.
