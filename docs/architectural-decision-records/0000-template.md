# NNNN. The decision, as one sentence

- Status: Accepted
- Date: YYYY-MM-DD, the day it was decided. When the guide names no date, the merge date of the PR that shipped it, and say that git is the source.
- Decider: who decided. When the guide names no one, the author of that PR, and say that git is the source.
- Issues and PRs: #N, #M
- Cited in code as: the issue and PR numbers that source comments cite for this decision, or "none"
- Guide: [`path/CLAUDE.md`](../../CLAUDE.md), the paragraph or bullet that states the rule today

## Context

What forced a choice. Keep it to one short paragraph.

## Decision

What was chosen, stated so a reader can check the code against it.

## Evidence

The measurements that settled it, each with the date it was taken. A limit that `GET /api/capabilities` publishes is dated history here: say what it was, and point at the endpoint for today's value.

## Alternatives rejected

Each option that was tried or considered, and why it lost. An earlier decision that this one reversed goes here too.

## Consequences

What holds the decision in place (a test, a lint check, a type, a mirrored constant), and what it costs.
